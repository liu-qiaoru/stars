# Phase 9A-C2：Qwen3-VL-Plus / Flash 新盲测报告

## 结论

两个模型都不应进入生产多帧复核。Qwen3-VL-Plus 的 30 条多数票准确率为 16/30
（53.3%），Qwen3-VL-Flash 为 15/30（50.0%）；Plus 只多答对 1 条，这个差距不足以证明
质量优势。Plus 的估算费用约为 Flash 的 7.1 倍，平均响应时间约为 2.0 倍。

更关键的是，人工参考答案中的 7 条 1 级“部分相关”样本，两个模型都没有一条多数票判断
正确：它们全部被压到 0 级或抬到 2 级。两者虽然三次重复很稳定，但不少错误也是稳定错误，
因此高稳定率不能解释成高准确率。Phase 9B～9D 继续跳过，生产检索仍保持 Phase 8 的
SigLIP2、Caption、语音全文和 RRF 排序。

## 主要指标

| 指标 | Qwen3-VL-Plus | Qwen3-VL-Flash | 本次含义 |
| --- | ---: | ---: | --- |
| 调用成功率 | 90/90，100% | 90/90，100% | 请求成功且返回可校验 JSON 的比例 |
| 三次稳定率 | 28/30，93.3% | 29/30，96.7% | 同一场景三次等级完全相同的比例；越高越稳定，但不保证正确 |
| 多数票准确率 | 16/30，53.3% | 15/30，50.0% | 每题取三次多数等级，再与冻结人工等级比较 |
| 单次输出准确率 | 49/90，54.4% | 44/90，48.9% | 90 次独立输出中与人工等级相同的比例；重复调用不等于 90 个独立样本 |
| 加权 Cohen's kappa | 0.4862 | 0.3820 | 扣除偶然一致，并让 0↔2 错误比 0↔1 更严重；越接近 1 越好 |
| 平均响应时间 | 4.411 秒 | 2.203 秒 | 每次同步调用的算术平均耗时，越低越快 |
| P95 响应时间 | 6.502 秒 | 3.182 秒 | 95% 成功调用不超过该耗时；越低越快 |
| 估算费用 | 0.379407 元 | 0.05349405 元 | 按供应商返回 token 和核对单价计算；控制台账单是最终事实 |

P95（第 95 百分位）是把 90 个耗时从小到大排列后观察靠近最慢端的位置，用来发现长尾
慢请求。总运行时间为 632.016 秒，约 10 分 32 秒；两个模型合计估算 0.43290105 元，低于
用户授权的 2 元上限，没有发生未知费用失败。

原始报告中的 `providers.exact_case_accuracy` 使用更严格的“必须三次稳定且正确”口径，
因此 Flash 是 14/30；本报告的主指标使用预先约定的三次多数票，Flash 是 15/30。两个数字
回答的问题不同，不应混用。

## 等级错误结构

| 人工等级 | 样本数 | Plus 多数票正确 | Flash 多数票正确 |
| --- | ---: | ---: | ---: |
| 0：关键约束缺失或冲突 | 16 | 9 | 8 |
| 1：核心意图部分匹配 | 7 | 0 | 0 |
| 2：全部关键约束明确匹配 | 7 | 7 | 7 |

两个模型都能识别本组明确的 2 级正例，但不会保持人工协议中的“部分相关”边界。例如：

- `c2-06` 中人物确实在进食，但使用签子且没有盒饭，人工为 1；两个模型都判 0。
- `c2-16` 中可见筷子和多个餐盘，但不是分格餐盒，人工为 1；两个模型多数判 2。
- `c2-02`、`c2-23` 中人物只是经过并关门，人工为 0；两个模型稳定解释成靠门摆姿势并判 2。
- `c2-19` 要求人物拿着装有小龙虾的袋子或容器，模型把手持单只虾和桌上餐盒放宽解释为
  “一袋小龙虾”，两者稳定判 2，人工为 0。
- `c2-28` 的人物实际站在控制台前，人工两轮都判“不是坐姿”；两个模型却稳定声称人物
  坐着并判 2。

这说明问题不只是模型大小。当前 Prompt 只给自然语言查询，并要求模型直接输出 0/1/2；
它没有获得人工标注时逐项使用的必须条件和排除条件，模型会自行放宽“袋子”“摆姿势”或
“坐姿”等约束。Plus 和 Flash 在 26/30 条上的多数等级相同，也支持这是共同判断口径问题，
而不是单纯把 Flash 换成更贵的 Plus 就能解决。

## 建议

1. 不实施生产 Phase 9B，多帧 VLM 不加入当前检索链路。
2. 若继续研究，应先定义可由系统稳定生成的查询约束，例如把“用筷子吃盒饭”拆成“人物、
   筷子、盒饭、进食动作”并显式检查排除条件；这相当于改变复核协议，不能把本轮结果当作
   新方案的正式测试成绩。
3. 新 Prompt 可以先用本轮 30 条做错误分析和开发，但最终质量结论必须再使用模型和 Prompt
   都未见过的新盲测样本，避免针对这 30 条调规则后得到虚高分数。
4. 如果未来准确率接近，再比较成本；以本轮证据看，Plus 只多答对 1 条却约贵 7.1 倍、慢
   2 倍，没有替代 Flash 或接入生产的性价比依据。
