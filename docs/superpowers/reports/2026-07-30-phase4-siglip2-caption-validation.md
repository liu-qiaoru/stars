# Phase 4：Caption 文本向量与 SigLIP2 验证报告

## 结论

- Caption 文本模型 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
  在 Apple MPS 上真实加载成功，输出 384 维单位向量。
- SigLIP2 `google/siglip2-base-patch16-224` 在 CPU 和 Apple MPS 上真实加载成功，
  图片与查询文本输出均为 768 维。
- 图片、视频帧、同步查询文本现在统一使用同一 SigLIP2 checkpoint。Caption 继续使用独立
  多语言文本模型；Worker 写入前会拒绝模型名称、版本或维度不一致的向量。
- SigLIP → SigLIP2 的维度虽然同为 768，但语义空间不同。Server 现在会同时检查 Qdrant
  维度和 PostgreSQL Vector Ref 模型配置，必要时重建 Collection 并重置为 `pending`。

## 测试环境

- 日期：2026-07-30
- 机器：Apple Silicon M5，32 GiB 内存
- Python：3.12.13
- PyTorch：2.13.0
- Transformers：4.57.6
- 测试图片：`apps/web/public/demo-media-contact-sheet.png`
- 图像/文本预处理：显式 `use_fast=true`，避免 Transformers 默认值升级造成向量漂移
- 英文查询：`a contact sheet with six different media thumbnails`
- 中文查询：`一张包含六个不同媒体缩略图的联系表`

## Caption 文本向量

| 项目 | 结果 |
| --- | ---: |
| 设备 | MPS |
| 向量维度 | 384 |
| 模型加载 | 5.2908 秒 |
| 首次文本推理 | 0.0792 秒 |
| 热模型文本推理 | 0.0053 秒 |
| 向量 L2 范数 | 1.0 |

L2 范数是向量各数字平方和再开平方；归一化后的合理值是 1。这里得到 1.0，证明本次输出
已成功归一化。索引与查询可比较还依赖同一模型、Tokenizer 和平均池化实现，本阶段通过共享
`TransformerTextEmbedder` 和模型身份守卫共同保证。首次推理包含设备初始化，热推理代表
模型常驻后的单次耗时，数值越小越好。本结果只验证模型链路，不代表完整搜索 API 延迟。

## SigLIP2 CPU

| 项目 | 结果 |
| --- | ---: |
| 向量维度 | 768 |
| 首次下载并加载 | 63.4041 秒 |
| 缓存后模型加载 | 9.4475 秒 |
| 首次图片推理 | 0.1007 秒 |
| 热模型图片推理 | 0.0623 秒 |
| 首次英文文本推理 | 0.0335 秒 |
| 热模型英文文本推理 | 0.0175 秒 |
| 中文文本推理 | 0.0177 秒 |
| 加载后常驻内存 RSS | 883,752,960 字节，约 0.82 GiB |
| 进程峰值内存 RSS | 1,607,778,304 字节，约 1.50 GiB |

RSS（Resident Set Size，常驻内存）表示进程当前占用的物理内存；越低越节省内存。峰值是本次
进程生命周期内观察到的最大值。首次加载包含网络下载，不能与缓存后的 MPS 加载时间直接比较。

## SigLIP2 Apple MPS

MPS（Metal Performance Shaders）是 Apple 芯片上的 GPU 加速接口。

| 项目 | 结果 |
| --- | ---: |
| 向量维度 | 768 |
| 缓存后模型加载 | 9.4472 秒 |
| 首次图片推理 | 0.1356 秒 |
| 热模型图片推理 | 0.0413 秒 |
| 首次英文文本推理 | 0.0124 秒 |
| 热模型英文文本推理 | 0.0078 秒 |
| 中文文本推理 | 0.0070 秒 |
| 加载后常驻内存 RSS | 813,727,744 字节，约 0.76 GiB |
| 进程峰值内存 RSS | 928,120,832 字节，约 0.86 GiB |

MPS 首次图片推理较慢是首次建立 GPU 计算流程的成本；热模型图片和文本推理均快于本次 CPU
结果。两个设备输出相同的图文相似度，说明 CPU/MPS 路径在该样本上结果一致。

## 中英文单样本消融

消融测试是在其他条件不变时只替换一个因素，这里只替换查询语言。

| 查询 | 与测试图片的余弦相似度 |
| --- | ---: |
| 忠实英文查询 | 0.148415 |
| 中文原查询 | 0.090109 |

余弦相似度理论范围为 -1 到 1，数值越大表示当前模型认为图文方向越接近，但它不是相关概率，
也不能跨模型或跨通道直接比较。该样本中英文高出 0.058306，支持视觉通道使用忠实英文译文；
但样本量只有 1，不能据此声称英文对所有查询都更好。阶段 8 必须在冻结评测集上继续比较。

## 限制与阶段 7 验证

- 本报告不写 PostgreSQL 或 Qdrant，只验证真实模型、预处理、投影维度、设备和单样本输出。
- Ollama Qwen2.5-VL 已在同一机器上用项目示例图真实生成中文 Caption，但完整的
  `generate_caption → embed_text_asset → Qdrant → Search` 服务链路仍按计划在阶段 7
  从空库、空 Collection 重建时验证。
- MPS 与 CPU 测试是串行独立进程；内存数字是进程级观察值，不包含其他系统进程。
- 单图联系表不是正式检索评测集，不能用这些相似度判断产品搜索质量。
